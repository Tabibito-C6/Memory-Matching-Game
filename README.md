🎴 Genshin Impact Themed Memory Matching Game

A clean, web-based memory matching game built with HTML, CSS, and vanilla JavaScript. 

This project was created as a personal portfolio piece to practice web development, state management, and DOM manipulation. It features an endless mode, a streak-based scoring system, and local storage leaderboards.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Grid layout, responsive design, custom animations)
- **Vanilla JavaScript** (Game logic, audio handling, `localStorage`)
